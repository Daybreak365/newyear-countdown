# New Year Countdown (Fabric 26.3)

2027-01-01 00:00까지 남은 시간을 화면에 띄우는 카운트다운 HUD + 보신각 타종 모드.

## 빌드
```
./gradlew build        # build/libs/newyear-countdown-1.1.0.jar
```
Minecraft 26.3, Fabric Loader 0.19.5 이상, Java 25 필요. 서버·클라이언트 모두에 jar 와 Fabric API 필요. (Mod Menu 는 선택)
1.21.1 판은 커밋 `1cc92b3` 에 있습니다. 1.21.1 월드를 열면 오미쿠지·소원 기록은 새로 시작됩니다(저장 위치가 바뀜).

## 서버 설정 `config/newyearcountdown.json`
`zone`, `target`(ISO 로컬시각), 종료 시 `title`/`subtitle`/`chatMessage`.

## HUD
설정 화면(Mod Menu 또는 조작 설정의 "카운트다운 설정 열기" 키)에서 테마(크리스마스[기본]/겨울/클래식/골드), 위치, 크기(기본은 작게 0.75배), 마지막 30초 째깍 소리를 바꿀 수 있습니다.

## 보신각 타종대 (블록)
- 크리에이티브 "기능 블록" 탭의 **보신각**을 들면 설치될 모습이 **홀로그램**으로 보입니다(청록색). 겹치는 블록이 있어 놓을 수 없으면 홀로그램이 **빨간색**이 되고 설치가 막힙니다. 구조물 전체(폭 13칸, 깊이 5칸, 높이 7칸)가 하나의 블록이며, 어느 부분을 부수든 통째로 무너지고 하나만 드롭됩니다. 정면은 설치한 사람 쪽을 향합니다.
- **당목(통나무)을 우클릭**하면 타종 모드: 카메라가 부드럽게 보신각 정면의 3인칭 시점으로 이동하고, 플레이어가 당목 뒤쪽 손잡이를 두 손으로 잡고 일직선으로 섭니다. 마우스를 왼쪽으로 당겼다가 오른쪽으로 휘두르면 당목과 함께 플레이어가 앞뒤로 움직이며 종을 칩니다. 빠를수록 크게 울립니다. Shift 로 나가기.
- 한 번에 한 명만 사용할 수 있고, 다른 사람은 사용 중 메시지를 봅니다. 다른 사람 화면에서도 당목·종 흔들림과 팔 자세가 보입니다.
- 새해(카운트다운 0)가 되면 설치된 모든 보신각이 자동으로 33번 타종합니다.
- 블록은 곡괭이로 캐면 아이템으로 돌아옵니다.

## 오미쿠지 뽑기대 (블록)
- 크리에이티브 "기능 블록" 탭의 **오미쿠지 뽑기대**: 가로 3 x 깊이 3 x 높이 4칸의 작은 사당 모양(돌 기단, 붉은 기둥, 기와 지붕, 제단 위 팔각 뽑기통, 새전함·방울·등롱·에마). 들면 설치 홀로그램이 보이고(청록/겹치면 빨강), 구조물 전체가 하나의 블록처럼 설치·철거됩니다. 물속에는 설치할 수 없고, 지붕은 계단식으로 밟을 수 있습니다.
- 어디든 **우클릭**하면 방울이 울리고 통이 흔들리며 막대가 튀어나옵니다. 앞에 운세 쪽지가 놓이고 지붕 위에 결과 글자가 떠오르며, 결과에 맞는 효과(파티클·소리)가 납니다.
- 결과는 채팅 대신 **운세 종이 UI**로 뜹니다(번호, 운세 등급과 한자, 총평, 소원/재물/연애 풀이). 등급은 좋은 순으로 대길·중길·소길·말길·평·소흉·중흉·흉·대흉 의 9가지입니다. 소원/재물/연애 풀이는 운세마다 5가지 문구 중 하나가 종이별로 정해집니다. **받기** 버튼을 누르거나 화면을 닫으면 종이가 화면 아래 인벤토리(핫바) 쪽으로 빨려 들어갑니다.
- **첫 뽑기가 메인**입니다. 이 월드(서버)에서 처음 뽑은 운세는 붉은색·금빛의 정식 종이("첫 뽑기")로 보관되고, 이후의 뽑기는 청회색 톤의 "추가 뽑기 N회차" 종이로 구분됩니다. 인벤토리의 오미쿠지 칸은 뽑기통 아이콘이고, 추가 뽑기 수는 +N 으로 보입니다.
- 받아 둔 운세는 **인벤토리 화면 왼쪽의 오미쿠지 칸**을 눌러서만 볼 수 있습니다. 맨 왼쪽이 첫 뽑기이고 오른쪽으로 넘길수록 나중에 뽑은 종이입니다(최대 50개). 더 넘길 수 없는 쪽 화살표는 비활성화됩니다.
- 기록은 **서버(월드) 저장 데이터**에 플레이어별로 저장됩니다. 그래서 다른 서버나 맵과 섞이지 않고, 다른 컴퓨터로 접속해도 같은 기록이 보입니다. 대길이 나오면 서버 전체에 알림이 갑니다.
- 한 번에 한 명씩 뽑고(약 6초), 연출은 근처 모든 플레이어에게 똑같이 보입니다. 도끼로 캘 수 있습니다.
- **관리자 콘솔**: 뽑기대 뒤편 가운데의 작은 붉은 버튼을 누르고 숨김 기능 비밀번호를 넣으면, 서버의 모든 유저와 뽑은 장수가 나옵니다. 유저마다 **이미지 저장**을 누르면 그 유저가 뽑은 오미쿠지 전부(표지 + 종이)를 한 장의 PNG 로 게임 폴더의 `omikuji_exports/` 에 저장합니다. 표지에는 이름과 함께 **그 유저의 스킨을 입힌 플레이어 모델**이 그려지고, 목록에도 유저 얼굴이 보입니다. 비밀번호는 서버가 다시 확인합니다. 이미지는 창 크기에 맞춰 그려지니 창을 크게 할수록 선명합니다.

## 소원 연등 (소원 빌기)
- 아이템 **소원 연등**(기능 블록 탭, 또는 종이 2 + 실 1 + 횃불 1 로 제작)을 들고 우클릭하면 **소원 쓰기 화면**이 열립니다. 소원을 적고(최대 60자) "연등 날리기"를 누르면 눈앞에서 연등이 떠오릅니다(크리에이티브가 아니면 아이템 1개 소모).
- 연등은 **3D 모델**(팔각 종이 몸통, 대나무 테두리와 십자 살, 일렁이는 불꽃, 안쪽에서 번지는 불빛, 꼭대기 매듭과 술)이고, 종이 위에는 **내가 적은 소원 글씨**가 보입니다. 처음엔 열기로 부풀며 천천히 뜨다가 점점 빨라지고, 바람에 흔들리고 천천히 돌며 높이 올라갑니다. 벽이나 천장에 막히거나 물에 닿으면 꺼집니다.
- 눈에 보이지 않을 만큼 높이 올라가면(발사 지점에서 약 190칸, 직전 45칸 동안 점점 작아짐) 연등은 사라지지만, **소원 기록은 서버(월드) 저장 데이터에 남습니다**. 인벤토리 화면 왼쪽의 **소원 기록 칸**(소원을 한 번이라도 빈 뒤 나타남)이나 조작 설정의 "소원 기록 열기" 키로 내가 빈 소원들을 최근 것부터 다시 볼 수 있습니다.
- **발사기**에 소원 연등을 넣고 레드스톤 신호를 주면 소원 글씨 없는 연등이 한 개씩 하늘로 날아갑니다(여러 개를 연달아 띄우거나 클럭 회로로 연등 쇼를 만들 수 있고, 소원 기록에는 남지 않습니다). 연등의 빛번짐은 배경을 가리지 않고 빛만 더해지도록 그립니다.
- 기록은 서버/월드별로 따로 저장되고, 다른 컴퓨터로 접속해도 같습니다.

## 세배
- **B 키**(조작 설정 "세배하기")를 누르면 남자 큰절 순서대로 절합니다(약 6초). 두 손을 이마로 올리고, 오른발을 딛은 채 왼 무릎·오른 무릎 순으로 꿇어 발뒤꿈치 위에 앉은 뒤, 두 손과 팔꿈치를 바닥에 대고 이마를 숙였다가 오른 무릎부터 세우며 일어납니다. 무릎·팔꿈치가 실제로 접히도록 플레이어와 갑옷 모델의 팔다리를 두 마디로 나눴습니다(평소 모습은 그대로). 동작은 주변 플레이어에게도 보이고(1인칭에서는 시점도 함께 낮아짐), 움직이면 취소됩니다. 땅 위에 서 있을 때만 할 수 있습니다.
- 5칸 안의 플레이어를 바라보고 절하면 그 사람에게 세배한 것으로 처리됩니다. 받은 사람은 행운 5분, 절한 사람은 세뱃돈으로 경험치 30을 받습니다. 보상은 같은 상대에게 하루 한 번입니다.

- **2027 캡슐토이**는 우클릭을 꾹 눌러 열면 랜덤 굿즈가 나옵니다. 6가지 색이 있습니다.

### 윷판
- 설치한 사람 쪽에 **붉은 양털(던지는 자리)** 이 오도록 3x3 으로 놓입니다. 어느 조각을 부숴도 판 전체가 치워지고 아이템은 한 번만 나옵니다.
- 규칙은 자동입니다. 판 위에 **누구 차례인지, 남은 이동(던진 결과), 던질 수 있는지**가 떠 있습니다. 빨강부터 번갈아 하며, 차례인 쪽이면 누구든 조작할 수 있습니다.
- **던지기**: 붉은 양털 우클릭. 윷·모는 한 번 더 던지고, 나온 결과는 '남은 이동'에 쌓입니다.
- **말 고르기**: 판 위의 우리 말, 또는 판 옆 대기 자리(빨강 왼쪽, 파랑 오른쪽)를 우클릭. 남은 이동이 하나뿐이면 바로 움직이고, 여러 개면 갈 수 있는 칸이 결과 이름(도·개·걸…)과 함께 빛나니 그중 하나를 누릅니다. 웅크리고 우클릭하면 선택 취소.
- 모서리나 가운데(방)에서 멈춘 말은 다음에 지름길로 꺾고, 같은 칸의 우리 말은 업혀서 함께 움직입니다. 상대 말이 있는 칸에 가면 잡아서 대기 자리로 돌려보내고 한 번 더 던집니다. 출발점(참먹이)을 지나면 골인, 네 말이 모두 골인하면 승리.
- 웅크리고 붉은 양털을 두 번 누르면 새 판. 판이 끝난 뒤에는 그냥 던지면 새 판이 시작됩니다.

## 컬링
- **컬링 하우스**(파랑·하양·빨강 양털)를 얼음 끝에 놓으면 바닥에 **5x5칸(반지름 2.5칸) 양털 픽셀아트 과녁**이 깔립니다. 블록은 얇고 충돌이 없어 스톤이 그 위로 지나갑니다. 과녁 위에는 **엔드·점수·차례·남은 스톤(●)** 이 떠 있고, 지금 점수가 나는 스톤 아래에는 금빛 고리가 깜빡입니다.
- **컬링 스톤**(빨강/노랑, 다듬은 안산암 2 + 염료): 우클릭을 꾹 눌러 힘을 모았다가(2초면 최대) 놓으면 바라보는 쪽으로 미끄러집니다. 모으는 동안 **예상 경로가 점선으로**, 멈출 자리가 고리로 보입니다. 그냥 놓으면 시계 방향으로 돌며 오른쪽으로, 웅크리고 놓으면 왼쪽으로 휩니다. 느려질수록 더 많이 휩니다.
- 얼음·꽁꽁 언 얼음·파란 얼음 위에서 잘 미끄러지고(파란 얼음이 가장 멀리), 다른 블록 위에서는 금방 멈춥니다. 스톤끼리 부딪히면 튕겨 나가고, 벽에 부딪히면 반쯤 튕깁니다.
- **컬링 브룸**: 꾹 누르고 있으면 앞쪽 3칸 안에서 미끄러지는 스톤 앞을 쓸어("쓸어라!"), 덜 느려지고 덜 휘게 합니다.
- **경기 규칙**: 4엔드, 엔드마다 팀당 스톤 4개. 빨강부터 번갈아 던지며, 차례가 아니거나 스톤을 다 던진 팀은 던질 수 없습니다. 스톤이 멈출 때마다 테이크아웃·버튼·중심까지 거리·과녁 밖 같은 결과와 현재 상황을 알려 줍니다.
- 8개를 모두 던지면 엔드 점수(가운데에 가장 가까운 팀이, 상대의 가장 가까운 스톤보다 안쪽에 있는 자기 스톤 수만큼)가 화면 가운데 제목으로 뜨고, 점수를 낸 팀이 다음 엔드를 먼저 던집니다. 스톤은 잠시 뒤 던진 사람에게 돌아옵니다(크리에이티브 제외). 4엔드가 끝나면 승리/무승부 발표, 그다음 던지면 새 경기.
- 하우스 우클릭: 점수 보기 / 웅크리고 우클릭: 주변 스톤 회수하고 새 경기. 스톤은 우클릭하거나 때려서 집을 수 있습니다.

## 아이템 모델 / 텍스처
- 보신각 타종대, 오미쿠지 뽑기대, 소원 연등, 가챠 머신 아이템과 2027 안경은 3D 모델입니다. 캡슐과 나머지 굿즈는 바닐라 느낌의 16x16 픽셀아트, 윷판은 48x48(블록당 16px) 픽셀아트 텍스처입니다.
