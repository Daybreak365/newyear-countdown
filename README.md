# New Year Countdown (Fabric 1.21.1)

2027-01-01 00:00까지 남은 시간을 화면에 띄우는 카운트다운 HUD + 보신각 타종 모드.

## 빌드
```
./gradlew build        # build/libs/newyear-countdown-1.0.0.jar
```
서버·클라이언트 모두에 jar 와 Fabric API 필요. (Mod Menu 는 선택)

## 서버 설정 `config/newyearcountdown.json`
`zone`, `target`(ISO 로컬시각), 종료 시 `title`/`subtitle`/`chatMessage`.

## HUD
설정 화면(Mod Menu 또는 조작 설정의 "카운트다운 설정 열기" 키)에서 테마(크리스마스[기본]/겨울/클래식/골드), 위치, 크기(기본은 작게 0.75배), 마지막 30초 째깍 소리를 바꿀 수 있습니다.

## 보신각 타종대 (블록)
- 크리에이티브 "기능 블록" 탭의 **보신각**을 들면 설치될 모습이 **홀로그램**으로 보입니다(청록색). 겹치는 블록이 있어 놓을 수 없으면 홀로그램이 **빨간색**이 되고 설치가 막힙니다. 구조물 전체(폭 13칸, 깊이 5칸, 높이 7칸)가 하나의 블록이며, 어느 부분을 부수든 통째로 무너지고 하나만 드롭됩니다. 정면은 설치한 사람 쪽을 향합니다.
- **당목(통나무)을 우클릭**하면 타종 모드: 카메라가 부드럽게 보신각 정면의 3인칭 시점으로 이동하고, 플레이어가 당목 뒤쪽 손잡이를 두 손으로 잡고 일직선으로 섭니다. 마우스를 왼쪽으로 당겼다가 오른쪽으로 휘두르면 당목과 함께 플레이어가 앞뒤로 움직이며 종을 칩니다. 빠를수록 크게 울립니다. Shift 로 나가기.
- 한 번에 한 명만 사용할 수 있고, 다른 사람은 사용 중 메시지를 봅니다. 다른 사람 화면에서도 당목·종 흔들림과 팔 자세가 보입니다.
- 새해(카운트다운 0)가 되면 설치된 모든 보신각이 자동으로 33번 타종합니다.
- 블록은 곡괭이로 캐면 아이템으로 돌아옵니다.

## 오미쿠지 뽑기대 (블록)
- 크리에이티브 "기능 블록" 탭의 **오미쿠지 뽑기대**: 가로 3 x 깊이 3 x 높이 4칸의 작은 사당 모양(돌 기단, 붉은 기둥, 기와 지붕, 제단 위 팔각 뽑기통, 새전함·방울·등롱·에마). 들면 설치 홀로그램이 보이고(청록/겹치면 빨강), 구조물 전체가 하나의 블록처럼 설치·철거됩니다. 물속에는 설치할 수 없고, 지붕은 계단식으로 밟을 수 있습니다.
- 어디든 **우클릭**하면 방울이 울리고 통이 흔들리며 막대가 튀어나옵니다. 앞에 운세 쪽지가 놓이고 지붕 위에 결과 글자가 떠오르며, 결과에 맞는 효과(파티클·소리)가 납니다.
- 결과는 채팅 대신 **운세 종이 UI**로 뜹니다(번호, 대길~대흉, 총평, 소원/재물/연애 풀이). **받기** 버튼을 누르거나 화면을 닫으면 종이가 "슈웅" 하고 핫바 오른쪽의 **오미쿠지 칸**으로 날아가 보관됩니다. 이 칸은 처음 받기 전에는 없다가 첫 종이가 닿는 순간 나타납니다.
- **첫 뽑기가 메인**입니다. 이 월드(서버)에서 처음 뽑은 운세는 붉은색·금빛의 정식 종이("첫 뽑기")로 보관되고, 이후의 뽑기는 청회색 톤의 "추가 뽑기 N회차" 종이로 구분됩니다. 오미쿠지 칸 아이콘에는 첫 뽑기의 운세 색이 표시되고, 추가 뽑기 수는 +N 으로 보입니다.
- 받아 둔 운세는 **인벤토리 화면 오른쪽의 오미쿠지 칸**을 눌러 다시 볼 수 있습니다(첫 뽑기 → 최근 추가 뽑기 순, 좌우로 넘기기, 최대 50개). 조작 설정에서 "오미쿠지 보관함 열기" 키를 지정해도 열립니다.
- 기록은 **서버(월드) 저장 데이터**에 플레이어별로 저장됩니다. 그래서 다른 서버나 맵과 섞이지 않고, 다른 컴퓨터로 접속해도 같은 기록이 보입니다. 대길이 나오면 서버 전체에 알림이 갑니다.
- 한 번에 한 명씩 뽑고(약 6초), 연출은 근처 모든 플레이어에게 똑같이 보입니다. 도끼로 캘 수 있습니다.

## 소원 연등 (소원 빌기)
- 아이템 **소원 연등**(기능 블록 탭, 또는 종이 2 + 실 1 + 횃불 1 로 제작)을 들고 우클릭하면 **소원 쓰기 화면**이 열립니다. 소원을 적고(최대 60자) "연등 날리기"를 누르면 눈앞에서 연등이 떠오릅니다(크리에이티브가 아니면 아이템 1개 소모).
- 연등은 **3D 모델**(팔각 종이 몸통, 대나무 테두리와 십자 살, 일렁이는 불꽃, 안쪽에서 번지는 불빛, 꼭대기 매듭과 술)이고, 종이 위에는 **내가 적은 소원 글씨**가 보입니다. 처음엔 열기로 부풀며 천천히 뜨다가 점점 빨라지고, 바람에 흔들리고 천천히 돌며 높이 올라갑니다. 벽이나 천장에 막히거나 물에 닿으면 꺼집니다.
- 눈에 보이지 않을 만큼 높이 올라가면(발사 지점에서 약 190칸, 직전 45칸 동안 점점 작아짐) 연등은 사라지지만, **소원 기록은 서버(월드) 저장 데이터에 남습니다**. 인벤토리 화면 오른쪽의 **소원 기록 칸**(소원을 한 번이라도 빈 뒤 나타남)이나 조작 설정의 "소원 기록 열기" 키로 내가 빈 소원들을 최근 것부터 다시 볼 수 있습니다.
- **발사기**에 소원 연등을 넣고 레드스톤 신호를 주면 소원 글씨 없는 연등이 한 개씩 하늘로 날아갑니다(여러 개를 연달아 띄우거나 클럭 회로로 연등 쇼를 만들 수 있고, 소원 기록에는 남지 않습니다). 연등의 빛번짐은 배경을 가리지 않고 빛만 더해지도록 그립니다.
- 기록은 서버/월드별로 따로 저장되고, 다른 컴퓨터로 접속해도 같습니다.

## 2027 캡슐토이 가챠 머신
- **가챠 머신**(2칸 높이 블록, 철괴 3 + 유리 3 + 붉은 염료 2 + 호퍼 1 조합, 또는 모드 탭)을 우클릭하면 캡슐 하나가 나옵니다(무료, 연출 중에는 다른 사람이 못 돌림).
  연출(약 2초): 머신이 움찔 → 손잡이가 1.5바퀴 돌며 머신이 떨리고, 돔 안 캡슐이 층마다 반대로 소용돌이치며 튀고 마퀴 전구가 쫓아감 → 배출구 덮개가 열리며 캡슐이 밀려나와 받침대로 구르다 두 번 튕기고 안착 → 반짝이 후 지급.
- **2027 캡슐토이**를 들고 우클릭을 **꾹 눌러** 까면 랜덤 기념품이 인벤토리로 들어옵니다. 까는 동안 캡슐이 **좌우로 달그락 흔들리다가(손에 든 모델이 실제로 흔들림) 80%쯤에서 쩍 갈라지며 빛이 새고**, 다 열리면 색종이가 터집니다. 캡슐은 6가지 색이 각각 별도 3D 모델입니다.
- 기념품 9종도 모두 3D 모델이며, **쓰는 순간 모델이 실제로 바뀝니다**(쿨다운·사용 상태에 따라 흔들림/열림/불꽃/터짐 모델로 전환):
  - 2027 안경: 머리 칸에 착용(3인칭에서 렌즈·프레임·별 장식이 보임). **쓰고 웅크리면** 머리 위로 파티 불꽃.
  - 새해 복주머니: 우클릭 → 흔들리며 금화가 튀고 덕담 한 줄, **웅크리고 우클릭** → 오늘의 행운 번호 6개.
  - 2027 양 인형: 우클릭 → 납작하게 눌리며 하트와 「메~」. **양이나 다른 생물에게 우클릭**하면 쓰다듬기.
  - 보신각 종 미니어처: 우클릭 → 좌우로 딸랑. **빠르게 이어 치면 음이 올라가고** 7번째에 폭죽과 새해 인사.
  - 세뱃돈 봉투: 우클릭 → 봉투가 열리고 지폐가 보이며 금액(1만~100만 원)이 나옵니다.
  - 2027 미니 달력: 우클릭 → 윗장이 넘어가며 **새해까지 D-day**(서버 카운트다운 기준)를 표시.
  - 폭죽 키링: 우클릭을 **꾹** → 심지에 불이 붙고(불꽃 모델) 다 타면 팡! 색종이와 폭음. 중간에 놓으면 불씨만 꺼집니다.
  - 새해 축하 사이다: 우클릭을 **꾹** 눌러 병을 흔들수록(거품 모델이 좌우로 흔들림) 세게 터집니다. 놓으면 바라보는 방향으로 거품이 뿜어지고 **불을 꺼 줍니다**. 끝까지 흔들면 자동으로 뻥!
  - 황금 2027 배지: 항상 반짝이고(인챈트 광택), 우클릭하면 별빛이 터지는 모델로 바뀝니다. 아주 희귀, 뽑으면 서버 전체에 알림.
- 확률은 `gacha/Souvenirs.java` 의 가중치로 조절합니다.

## 아이템 3D 모델 / 텍스처
- **보신각 타종대 · 오미쿠지 뽑기대 · 소원 연등 · 가챠 머신** 아이템은 납작한 아이콘이 아니라 각각 **별도로 만든 3D 모델**(인벤토리·손·바닥·액자에서 모두 입체)입니다. 보신각은 기와 지붕·기둥·대종·당목, 오미쿠지는 사당·팔각 뽑기통·방울·새전함, 연등은 팔각 종이 몸통에 소원 글씨와 불꽃, 가챠 머신은 캡슐이 가득한 돔과 손잡이를 담았습니다.
- 캡슐/기념품은 이전 32px 평면 텍스처 대신 모델마다 **최대 512~1024px 텍스처 아틀라스**를 쓰고, 구·원통 조명, 광택, 천/나무/금속 질감, 문자(2027·달력·라벨)가 텍스처에 구워져 있습니다. 안경 착용 레이어도 렌즈 반사·금 프레임·별 장식으로 다시 그렸습니다.
- 모델과 텍스처는 `tools/modelgen`(파이썬)이 생성합니다. 수정/재생성은 `tools/modelgen/README.md` 참고.
